Run It Local — No Quota, Ever

MAC · WINDOWS · LINUX

The whole model is open. On a MacBook it runs on Apple Silicon through MLX; on a GPU box it needs under 4 GB of VRAM. First run downloads the weights, then everything happens on your machine — no quota, no queue, no account.

terminal — local install
# one-time install (needs Python 3.11–3.12)
curl -LsSf https://astral.sh/uv/install.sh | sh

git clone https://github.com/ACE-Step/ACE-Step-1.5.git
cd ACE-Step-1.5
uv sync

# launch the console on your own machine
uv run acestep   # → http://localhost:7860
